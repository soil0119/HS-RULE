# HS-RULE 웹/API 및 UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. 구현자는 하위 에이전트를 만들지 않는다. 작업별 독립 리뷰와 최종 리뷰를 수행한다.

**Goal:** RAG 구현을 제외한 인증·PDF 문서 보관 API, Local Codex 생성 UI, 도메인/실행/CI를 완성한다.

**Architecture:** FastAPI 앱 팩토리와 Postgres 일반 문서 저장소를 사용한다. PDF 페이지 파싱은 모델 없이 동작하고 RAG는 주입 인터페이스로 분리한다. HTML/CSS/JS UI를 서버에 연결한다.

**Tech Stack:** Python 3.11, FastAPI, psycopg2, pdfminer.six, PyJWT, HTML/CSS/JS, GitHub Actions.

**Spec:** [확정 범위](../../app-scope.md), [진단](../../project-diagnosis.md), 이슈 #6·#7·#8. 사용자 명시적 범위 변경을 반영했다.

## Global Constraints

- RAG·LangChain·청킹·임베딩·벡터 검색·모델 생성은 구현하지 않는다. 담당자는 sumiiniee(#9/#10/#11)다.
- 기존 RAG 초안은 codex/pdf-foundation / Draft PR #2에 보존하고 이 PR 계열에 포함하지 않는다.
- 기존 사용자 작업·원본 ZIP·참고 크롤러·원래 JSON을 임의 삭제하지 않는다. 기존 JSON을 지식 데이터 폴백으로 사용하지 않는다.
- PDF 원본은 uploads/{server_id}.pdf, 페이지 번호는 1부터, 파일명은 표시용이다. private 기본값과 public 조회 경계를 지킨다.
- 사용자 PDF·DB·캐시·비밀값은 Git에 넣지 않는다. 원본 ZIP의 쿠키를 사용/외부 전달하지 않는다.
- 기본 관리자 비밀번호·임시 서명키를 허용하지 않는다. 미설정 상태에서도 UI/liveness는 열린다.
- 질의/분석의 RAG 미연결 상태를 503으로 표현하고 정상 AI 성공으로 가장하지 않는다.
- 도메인은 https://hs.officeworkkt.com. DNS·TLS·배포는 실제 검증 없이 완료를 주장하지 않는다.
- 기능별로 자주 커밋하고 이슈별 PR을 분리한다. 사용자 머지로 남긴다.

## Review Focus

- 경로형 파일명·DB/파일 실패가 외부 파일이나 기존 문서를 손상하지 않는가.
- public/private 목록·원본 PDF·질의 근거가 서버 권한으로 제한되는가.
- 잘못된 메시지·손상/스캔/과대 PDF·외부 응답이 적절한 오류로 처리되는가.
- 생성 UI의 동적 문자열·URL·로그인 세션과 모바일 메뉴가 안전하게 동작하는가.
- CI와 테스트가 RAG/실제 키 없이 앱 코드의 실제 동작을 검증하는가.

# HS-RULE 웹/API 및 UI Implementation Plan

이 문서는 일반 웹/API 작업과 사용자 결정으로 이슈로 이관한 후속 작업을 기록한다. 이번 게시 범위는 Task 1과 생성된 디자인 산출물이다.

**목표**

공식 공개 규정 본문을 서비스의 주 자료로 삼고, 관리자가 선택 PDF를 별도로 보관할 수 있도록 한다. FastAPI와 PostgreSQL의 일반 앱 계약을 바탕으로 수집·색인·검색·생성·UI를 담당 이슈에서 연결한다.

**기술 구성**

Python 3.11, FastAPI, psycopg2, pdfminer.six, PyJWT, HTML/CSS/JS. 현재 웹 API는 앱 팩토리와 PostgreSQL 일반 문서 저장소를 사용한다. RAG는 주입 인터페이스로 연결한다.

[확정 범위](../../app-scope.md) · [기준 진단](../../project-diagnosis.md) · [일반 API 계약](../../api-contract.md)

## 담당과 구현 경계

- `neicebee`는 일반 백엔드·공식 공개 규정 크롤러·일반 DB를 맡는다. `sumiiniee`는 RAG·LangChain·청킹·임베딩·벡터 DB를 맡는다. PC·모바일 프론트엔드와 한국어·영어 흐름의 담당 예정자는 `IVEhades`이며 초대 수락 후 GitHub 배정을 확인한다.
- PDF 색인 기반 PR #2는 사용자가 main에 병합했다. 앱 PR #33에 포함된 RAG 관련 작업은 어댑터 계약이다. [PR #2](https://github.com/soil0119/HS-RULE/pull/2) · [PR #33](https://github.com/soil0119/HS-RULE/pull/33)
- 기존 사용자 작업·원본 ZIP·참고 크롤러·원래 JSON은 보존한다. 공식 공개 본문을 수집·검증한 뒤 지식 자료로 사용한다. 사용자 PDF·DB·캐시·비밀값은 Git에 넣지 않는다.
- 선택 PDF는 `uploads/{server_id}.pdf`에 두고 페이지를 1부터 기록한다. 파일명은 표시용이며 공개 범위 기본값은 `private`다.
- 관리자 로그인은 명시적 자격 증명을 사용한다. 설정 누락 상태에서도 UI와 liveness가 열린다. 질의·분석의 RAG 미연결 상태는 503이다.
- 공개 출처는 `https://hs.officeworkkt.com`이다. 실제 DNS·TLS·배포 확인은 후속 운영 이슈에서 추적한다. 기능별로 PR을 분리하고 사용자 머지로 남긴다.
